ORcode 是一个可自带模型的智能体开发工具。接入任意 OpenAI 兼容端点（含本地端口如 localhost:11434），定义多个「岗位」，让指挥、规划、研发、检验各司其职，插件从本官网一键下载。

为什么是 ORcode

不是又一个聊天框，而是一套可编排的多模型工作流。

🔌

自带模型

填 base_url + api_key + model 即可接 DeepSeek / OpenRouter / Ollama / 通义 / 智谱 / 月之暗面等任意 OpenAI 兼容服务，可指向本地端口。

🧩

可下载插件

文件读写、Shell、联网内置；更多能力从本官网插件中心一键下载，放到本地即生效。

👥

多岗位协作

一个下指令、一个写 plan、不同领域模型分工、一个做检验——全部由你配置，也可直接套预设。

🔁

检验补做回路

Verifier 不通过会自动派发补做任务，反滚雪球、保证交付真正完成。

🖥️

本地优先

数据留在你机器上，默认跑在 localhost:3000，浏览器里可视化看每个岗位的思考与工具调用。

⚡

零依赖

纯 Node.js 内置模块实现，没有脆弱的第三方依赖，克隆即跑、不会卡在安装。

一条流水线，四个岗位

从一句话任务，到被检验通过的交付物。

1
指挥 Director
把任务拆成互相独立的工作项，指定负责岗位。
→
2
规划 Planner
产出顺序执行计划，明确每步的岗位与依赖。
→
3
执行 Workers
多岗位按 plan 并行/串行工作，调用工具。
→
4
检验 Verifier
核对交付是否完成，不通过自动补做。

三步跑起来

  1. node bin/orcode.js init生成 .omni/config.json
  2. node bin/orcode.js serve浏览器打开 http://localhost:3000，填模型密钥
  3. node bin/orcode.js run "你的任务"或直接在网页里点「运行」
